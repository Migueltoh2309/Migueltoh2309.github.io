Autonomous Trajectory Generation for Pick-and-Place Tasks Using the Sawyer Robot

This project is based on the well-known pick-and-place action, which is commonly applied in both industrial and educational fields. In this project, the action is approached through the use of computer vision technology on the Sawyer robot, utilizing its two integrated cameras along with an external camera.

  • Computer Vision and Object Detection
  • Robotic Manipulation and Autonomous Task Execution
  • Robotic System Integration and Real-World Implementation Using ROS
